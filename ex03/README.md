## Why Git Makes Development Easier

### 1. Code Safety
- **Save Progress:** Every commit saves a working snapshot of your code.
- **Easy Undo:** If something breaks, you can easily go back to a working version.

### 2. Clear History
- **Full Log:** `git log` shows all changes made over time.
- **Track Changes:** You can see who changed the code, when, and why.

### 3. Better Teamwork
- **Work Together:** Multiple developers can work on the same project using branches.
- **Cloud Backup:** GitHub keeps a safe copy of the project online.
